# 现代简约客餐厅 · 柔光砖与新布局

![装修方案效果图](preview.png)

按用户最新要求调整：

- 不做吊顶：保留原始平顶，取消灯槽、周边装饰和嵌入式筒灯，使用明装薄吸顶灯。
- 木地板改为暖灰米色 1200 mm 柔光砖，客餐厅同方向连续铺贴，配同色细缝。
- 去掉冰箱；左侧沙发改为约 2.2 米长的双人沙发。
- 原右侧餐桌区域改为约 2.12 米宽、0.38 米深的通高鞋柜，带木色开放置物区。
- 餐桌移到左侧前段，采用直径约 1.05 米的圆形独脚石材桌，配置三把餐椅，保留右侧通行方向。

[下载可编辑 Blender 工程](photo_apartment.blend?raw=true)

Blender 4.3.2 制作；数字键盘 0 查看摄影机，F12 渲染。材质无需外部贴图。运行 `blender -b --python build_scene.py` 可生成工程与预览。

房间暂按 3.4 × 6.8 × 2.9 米估算。上述尺寸为方案假设；柜体深度、桌椅活动空间、过道净宽需实测后调整。本文件为装修概念方案。
