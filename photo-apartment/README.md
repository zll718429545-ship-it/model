# 照片重建：狭长客餐厅

![入口视角渲染](preview.png)

根据用户提供的室内照片，在 Blender 4.3.2 中重建。包括木地板、白色墙面与顶角线、银色双门冰箱、木框深色沙发、茶几、壁挂电视、尽头四门储物柜、白色大理石餐桌、三把深色餐椅、挂画及灯具。

- [下载 Blender 工程](photo_apartment.blend?raw=true)
- [查看渲染图](preview.png)
- `build_scene.py`：完整、可重复运行的建模脚本。

打开 `.blend`，数字键盘 0 查看摄影机，F12 渲染。家具、墙体和灯光为独立可编辑对象，材质均为程序化生成，无需外部贴图。

运行：`blender -b --python build_scene.py`。脚本会在同目录生成工程及预览图。

房间暂按宽 3.4 米、深 6.8 米、高 2.9 米估算。单张照片无法确定真实尺寸及遮挡部分；本工程为近似场景重建，挂画采用简化程序图案，并非照片级一比一复刻。
