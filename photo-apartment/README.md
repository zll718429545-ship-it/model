# 现代简约客餐厅

![现代简约装修效果](preview.png)

保留参考照片的狭长客餐厅格局，改为暖白、浅橡木、米灰与黑色细线条组成的现代简约方案。

- 暖白墙面、简洁顶面与线性灯光；餐区采用细长黑色吊灯。
- 浅橡木地板与沙发背景饰面，米灰软包座椅和中性色地毯。
- 低纹理浅色石材餐桌、无明装拉手柜门、单幅大尺寸抽象装饰画。
- 保留冰箱、沙发、茶几、电视、储物柜与餐桌的位置。

[下载可编辑 Blender 工程](photo_apartment.blend?raw=true)

Blender 4.3.2 制作；数字键盘 0 查看摄影机，F12 渲染。所有材质均为程序化材质，无外部贴图依赖。运行 `blender -b --python build_scene.py` 可在脚本同目录重新生成工程与预览。

房间暂按 3.4 × 6.8 × 2.9 米估算。本文件为装修风格概念方案，尺寸与隐蔽结构未实测。
